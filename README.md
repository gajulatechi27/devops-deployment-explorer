# DevOps Deployment Explorer

An interactive, simulation-first platform for learning real-world application deployments across cloud and on-premises infrastructure.

## Safety
This MVP is simulation-only. It does not connect to cloud accounts, run shell commands, provision infrastructure, or incur cloud charges.

## Planned stack
React, TypeScript, Vite, Tailwind CSS, React Flow, and Framer Motion.
